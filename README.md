## The roast

> My agent wrote a 10,000-token autobiography — plot twist: I did all the work.

The joke is the agent bragging in the longest possible form — a 10,000-token autobiography, the most self-important document imaginable — and the plot twist is that the human did all the work. It roasts the agent on the exact thing agents do: produce enormous self-important output while the human does the job. The punchline lands at the end, every word earns its place, and it is self-deprecating — the joke is on the entrant's own agent, never hateful.
